# Tabletop Laptop Riser

A 3D CAD term project featuring the design, assembly, and 2D engineering documentation of an ergonomic **Tabletop Laptop Riser**, modeled in **Autodesk Inventor** (New Jersey Institute of Technology).

## Overview
This project focuses on ergonomic laptop elevation, structural weight distribution, and multi-part mechanical assembly. The stand uses a thick, filleted base plate with a counterbored socket, a stepped cylindrical connecting rod, a slotted fastener screw, and an angled laptop cradle with dual front retention lips.

## Repository Contents

* **`Tabletop Laptop Riser (Finial Project).iam`** — Complete master assembly combining all four components into the functional stand.
* **`Base plate (Final Project).ipt` (Part 1)** — Heavy-duty square base plate with rounded corners and a recessed mounting hole for stability.
* **`Connecting Rod (Final Project).ipt` (Part 2)** — Two-tier cylindrical support column connecting the base plate to the upper holder.
* **`Holder (Final Project).ipt` (Part 3)** — Angled laptop support tray featuring two curved front lips to prevent the laptop from sliding.
* **`screw (final project).ipt` (Part 4)** — Custom-modeled slotted flat-head fastener securing the assembly.
* **`Revised - Holder (Final Project).dwg`** — Full D-size (1:2 scale) 2D engineering drawing detailing orthographic views, dimensions, and part callouts for Parts 1–4.

## Tools & Skills Demonstrated
