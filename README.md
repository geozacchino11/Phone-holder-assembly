# Tabletop Laptop Riser

A 3D CAD term project featuring the design, assembly, and 2D engineering documentation of an ergonomic **Tabletop Laptop Riser**, modeled in **Autodesk Inventor**.

## Overview
This project focuses on mechanical linkage design, structural weight distribution, and assembly constraints. The riser elevates a laptop to an ergonomic viewing height using a stable base plate, an upper support cradle, connecting rods, and custom fasteners.

## Files Included

* **`Tabletop Laptop Riser (Finial Project).iam`** — Complete master assembly bringing together all parts with functional mechanical constraints.
* **`Base plate (Final Project).ipt`** — Bottom support plate engineered to provide a stable footprint on a desk surface.
* **`Holder (Final Project).ipt`** — Upper tray designed to securely hold and support the laptop.
* **`Connecting Rod (Final Project).ipt`** — Linkage arms connecting the base plate and upper holder for elevation and structural support.
* **`screw (final project).ipt`** — Fastener component modeled to join the linkages and frame.
* **`Revised - Holder (Final Project).dwg`** — 2D engineering drawing containing updated dimensions, orthographic views, and design revisions for the laptop holder.

## Tools & Skills Demonstrated
* **Software:** Autodesk Inventor
* **Skills:** 3D Parametric Part Modeling, Multi-Part Assembly & Constraints, 2D Engineering Drafting & Revision Control
